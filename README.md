# Uznik MultiTool

Десктопный инструмент для управления своими Telegram-аккаунтами.
Интерфейс на Qt / PySide6, постоянный размер элементов **Comfortable**.

Это самостоятельная desktop-редакция: без сайта, Mini App, управляющих
Telegram-ботов, HTTP API, серверного деплоя и автоматической синхронизации с
чужим сервером. Репозиторий пока приватный; сборка предварительная.

## Быстрый старт на Windows

1. Установите 64-битный **Python 3.12 или новее** с Python Launcher (`py`).
   Для первой установки рекомендуется 3.12 из-за совместимости OCR-зависимостей.
2. Скачайте репозиторий через **Code → Download ZIP** и распакуйте в постоянную
   папку либо выполните `git clone https://github.com/Duerotator/uznik-multitool.git`.
   Для приватного репозитория нужен доступ в GitHub.
3. Дважды нажмите **`setup.bat`**. Он создаст отдельную `.venv`, установит
   Python-зависимости и Chromium для Telegram Web / розыгрышей, добавит ярлык
   **Uznik MultiTool** на рабочий стол. Интернет нужен для установки.
4. В открывшемся `.env` заполните **свои** `TELEGRAM_API_ID` и
   `TELEGRAM_API_HASH`, полученные на [my.telegram.org/apps](https://my.telegram.org/apps).
   Сохраните файл. Ключи никому не отправляйте.
5. Запускайте через ярлык **Uznik MultiTool** или двойным кликом по
   **`start_gui.bat`**. Команды больше копировать не нужно.

`setup.bat` можно запускать повторно: существующий `.env` и пользовательские
данные сохраняются. После перемещения папки пересоздайте ярлык через
`create_shortcut.bat`. Для запуска с видимым логом используйте `start_debug.bat`.

Ярлык и окно приложения имеют собственную иконку Uznik. Вспомогательные
утилиты доступны двойным кликом по **`toolbox.bat`**; описание и команды —
[scripts/README.md](scripts/README.md).

## Первые аккаунты и прокси

Приложение начинает работу с пустой базой. Добавляйте только свои сессии:
через интерфейс импорта, перетаскивание файлов либо папку `imports/`.
Рабочие сессии сохраняются в `data/sessions/`; группы и настройки аккаунтов
хранятся в `data/`. Используемый клиент Kurigram импортируется как `pyrogram`.
Также поддерживается Telethon, сессии этих клиентов имеют разные форматы.

Чтобы мультитул **создал свою новую сессию** из вашей существующей сессии,
положите `.session` в **`imports/auth_input/`**. В интерфейсе откройте
**Actions → External sessions → Process dropped sessions**. Кнопка
**Open auth_input** открывает нужную папку, рядом показано количество файлов.
Инструмент работает с временной копией, запрашивает код и пытается прочитать
свежее сообщение от Telegram (777000). Если нужно, спросит код / ваш 2FA.
Автообработка новых файлов включается отдельной галочкой и по умолчанию выключена.

После успешного создания файл очереди остаётся в `auth_input/processed/`,
ошибочный — в очереди. При перетаскивании `.session` внешний оригинал сохраняется.
JSON с `session_string` импортируется обычным способом, без запроса кода.
**Обычный `imports/` импортирует существующую авторизацию**, а не создаёт новую.
См. [памятку очереди](imports/auth_input/README.md).

В репозитории теперь есть пустые папки для всех desktop-путей; установка
и первый запуск восстанавливают недостающие каталоги и пустые шаблоны.
Фотографии для генерации добавляйте в `assets/avatar_packs/{male,female,unknown}/`.
Рабочих файлов в этих папках изначально нет.

Настройте свой прокси в интерфейсе или через `TELEGRAM_GLOBAL_PROXY` в `.env`.
Формат: `socks5://HOST:PORT` или `socks5://USER:PASSWORD@HOST:PORT`.
Прокси, VPN-подписки, чужие API-ключи и готовые сессии в комплект не входят.
Некоторые операции требуют рабочего прокси и не переключаются на прямое
соединение автоматически.

## Что доступно

- Аккаунты: группы, фильтры, выделение, проверка сессий и состояния,
  безопасность, Passkey, online-режим и расписание.
- Профили: генерация, применение, парсинг участников чатов, фильтрация и кэш,
  архив и привязки аккаунт ↔ профиль, загрузка и публикация историй.
- **Open acc** для одного выделенного аккаунта: отдельное постоянное окно
  Telegram Web, авторизация через имеющуюся сессию. 2FA вводится вручную либо
  берётся из настроек вашего аккаунта / `TELEGRAM_DIRECT_ACCESS_2FA_PASSWORD`.
- Чаты и действия, прогрев и сценарии; AI-диалоги при настройке своего API.
- Участие в поддерживаемых розыгрышах по ссылке на пост; отдельного
  управляющего Bot API бота в этой редакции нет.
- Логи и отображение прогресса операций. Массовые действия требуют
  подтверждения; перед применением проверьте активную группу и фильтры.

Лимиты Telegram зависят от аккаунта и операции. Premium не снимает FloodWait
и другие ограничения. Сначала проверяйте новые действия на одном аккаунте.
Некоторые функции обращаются к сторонним ботам или сервисам по вашему запуску.

## Дополнительные настройки

Все необязательные интеграции отключены, пока вы их не настроите в `.env`.
После изменения `.env` перезапустите приложение.

| Возможность | Настройки |
| --- | --- |
| AI-диалоги | `LLM_API_KEY`, `LLM_BASE_URL`, `LLM_MODEL`, `AI_ALLOWED_CHATS` |
| Почтовые коды | `EMAIL_DOMAIN`, `EMAIL_INBOX_API_URL`, `EMAIL_INBOX_TOKEN`; необходим свой inbox API |
| Источники списков прокси | `PROXY_SOURCE_URLS` — свои URL, разделённые `;`; по умолчанию список пуст |
| Внешний captcha-сервис | `SOLVECAPTCHA_KEY` — свой ключ, если он нужен конкретному розыгрышу; услуга может быть платной |
| Xray gateway | `PROXY_MODE=vpn_gateway`, `XRAY_EXECUTABLE` и своя подписка; см. ниже |

Gateway понимает VLESS-список по `VPN_VLESS_SUBSCRIPTION_URL` (обычный или
base64) либо локальный файл `VPN_VLESS_FILE`. Альтернатива — JSON-массив
Xray-конфигураций по `VPN_XRAY_SUBSCRIPTION_URL`. Xray устанавливается отдельно;
его путь укажите в `XRAY_EXECUTABLE`. Без этих настроек gateway не запускается.
Чтения подписок из Happ или подключения к заранее заданному серверу нет.

Chromium устанавливает `setup.bat`. Локальный OCR `ddddocr` входит в зависимости;
резервный Tesseract и FFmpeg для функций, которым они нужны, устанавливаются
отдельно и должны быть доступны в `PATH`. Они не нужны для открытия dashboard.
TgCrypto — необязательное ускорение MTProto: без него клиент работает, но может
быть медленнее. Он не включён в обязательную установку, чтобы отсутствие
совместимого Windows-wheel не блокировало запуск.

## Данные и безопасность

Никакие рабочие данные исходного проекта сюда не перенесены. В поставке нет
аккаунтов, фильтров, профилей, архивов, фотографий, паролей, прокси, токенов,
VPN-конфигураций или логов. Локальное состояние интерфейса имеет отдельное имя
`UznikMultiTool` и не наследует настройки исходного приложения.

`data/`, `imports/`, `.env`, пользовательские `templates/`, браузерные профили,
базы, логи и сессии исключены из Git. В Git входят только `.gitkeep` и памятки
пустых каталогов. Не используйте `git add -f` для рабочих файлов в этих путях.
Сессия и браузерный профиль дают доступ к аккаунту: храните их как пароль.
Для резервной копии закройте приложение и сохраните `data/`, `.env` и свои
шаблоны в защищённом месте. Не публикуйте такую копию в GitHub.

Приложение не является официальным клиентом Telegram. Используйте его только
для аккаунтов и данных, которыми вправе управлять, и соблюдайте правила сервисов.

## Если что-то не запускается

- Нет Python: установите Python с launcher, повторите `setup.bat`.
- Не установилась зависимость: посмотрите ошибку в окне установки; для OCR
  попробуйте Python 3.12 в отдельном окружении. Не удаляйте свою базу.
- Окно не открылось: запустите `start_debug.bat`; логи находятся в
  `data/logs/launcher.log`, `current_session.log`, `multitool.log` и `crash.log`.
- Telegram Web сообщает об отсутствии browser executable: повторите
  `setup.bat` или выполните `.venv\Scripts\python.exe -m playwright install chromium`.
- Не подключается аккаунт: проверьте свои API-ключи, формат сессии и прокси.
  Долгий FloodWait означает ограничение Telegram, его нужно дождаться.

При отправке лога удалите номера телефонов, session strings, пароли и токены.

## Обновление и разработка

Закройте приложение, выполните `git pull`, затем при изменённых зависимостях
запустите `setup.bat`. Ваши локальные данные не входят в обновление.
Для ZIP-установки обновляйте исходники с сохранением `.env`, `data/` и шаблонов.

Структура и команды проверок: [docs/PROJECT_MAP.md](docs/PROJECT_MAP.md) и
[tests/TEST_MAP.md](tests/TEST_MAP.md). Автономные проверки:

```powershell
.\.venv\Scripts\python.exe .\tests\run_checks.py fast
```

Они не запускают реальные Telegram-операции и не используют рабочие сессии.
