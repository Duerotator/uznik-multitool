# Данные, подключения и проверка исходников

Uznik MultiTool — приложение с доступом к Telegram-аккаунтам. До установки
проверьте исходники и зависимости; используйте только аккаунты, которыми вправе
управлять. Проект не является официальным клиентом Telegram, не обещает обхода
его ограничений и не гарантирует «100% безопасность».

## Локальные данные

| Место | Содержимое и риск |
| --- | --- |
| `.env` | Telegram API-ключи, настройки интеграций и, если указан, пароль 2FA |
| `data/accounts.json` | Метаданные аккаунтов; могут содержать email и сохранённый пароль 2FA |
| `data/sessions/`, исходные сессии в `imports/` | Авторизации Telegram; копирование позволяет получить доступ к аккаунту |
| `data/browser_profiles/` | Постоянные профили Chromium с авторизацией Telegram Web |
| `data/passkeys/` | Материалы ключей доступа; требуют защиты как пароль |
| `imports/emails/accounts.txt` | Ваш список почтовых логинов и паролей; хранится в открытом текстовом виде |
| `data/email_mailbox_bindings.json` | Закрепления ящиков за аккаунтами, без паролей |
| `data/profiles_archive/`, другие кэши | Сохранённые профили, изображения, видео и результаты проверок |
| `data/logs/` | Диагностика; может содержать номера, username, адреса почты и другие личные данные |

Приложение не обеспечивает общего шифрования файлов на диске. `.gitignore`
исключает рабочие данные из обычного Git-добавления, но не шифрует их и не
защищает от других пользователей компьютера, резервного копирования или `git add -f`.
Используйте права доступа ОС, шифрование диска и защищённые резервные копии.
Не отправляйте весь каталог приложения в публичные отчёты.

## Сетевые подключения

| Функция | Что передаётся и кому |
| --- | --- |
| Работа с аккаунтами | Запросы MTProto серверам Telegram; без прокси виден ваш IP |
| Open acc | Авторизация и действия в `web.telegram.org` через Chromium |
| Прокси / Xray | Трафик идёт через настроенного вами провайдера; пользовательские источники прокси и VPN-подписки запрашиваются при соответствующих действиях |
| IMAP / POP3 | Логин и пароль выбранному почтовому серверу по TLS; читаются сообщения для получения кода, отправка почты не используется |
| HTTP inbox | Адрес ящика, параметры поиска кода и настроенный токен вашему inbox API |
| AI-диалоги | Настроенному AI-провайдеру отправляются запрос, контекст диалога и имена участников; не включайте функцию для конфиденциальных чатов |
| Розыгрыши / Mini Apps | Сайтам выбранного розыгрыша передаются данные Telegram WebApp и запросы участия; это сторонние сервисы, не только Telegram |
| Внешний OCR | При использовании SolveCaptcha передаются изображение капчи и API-ключ этому сервису; локальный OCR не требует этого ключа |
| Загрузка ресурсов | Указанному вами источнику отправляется запрос на скачивание ресурсов |

Внешние интеграции настраиваются пользователем; участие, сообщения и массовые
действия могут изменять состояние аккаунтов. Не используйте рабочие сессии для
непроверенных сценариев. Настроенный неисправный прокси не обходится прямым
подключением; при отсутствии прокси прямое подключение разрешено.

## Установщик и права

`setup.bat` запускает читаемый `scripts/setup.ps1`. Он создаёт `.venv`,
устанавливает Python-пакеты из PyPI, скачивает Playwright Chromium и устанавливает
отсутствующие FFmpeg, Tesseract и Xray через WinGet. Источники и точные WinGet ID
описаны в [INSTALLATION](INSTALLATION.md). Установка внешних программ может
запрашивать UAC. Для обычной работы приложения права администратора не требуются.

`-ExecutionPolicy Bypass` относится к запускаемому процессу PowerShell, а не к
постоянному изменению политики компьютера. Скрипт создаёт `.env`, если его нет,
папки данных и ярлыки; не устанавливает службу приложения. Установка Xray не
включает gateway автоматически. Вариант `-SkipNativeTools` пропускает WinGet.

## Где проверять поведение

- `scripts/setup.ps1`, `scripts/windows/install_native_tools.ps1` — установка.
- `app/core/config.py`, `app/core/project_layout.py` — настройки и пути данных.
- `app/modules/direct_access.py`, `session_onboarding.py` — браузер и авторизация.
- `app/modules/email_inbox.py`, `email_mailbox.py` — чтение почтовых кодов.
- `app/modules/ai_companion.py`, `raffle_*.py`, `vpn_gateway.py` — внешние интеграции.
- `.github/workflows/` — команды публичных проверок и подготовки релиза.

Проверяйте результат workflow именно для скачанного коммита: значок в README
показывает состояние ветки, а не всех версий. Bandit и CodeQL ищут определённые
классы ошибок; pip-audit проверяет опубликованные сведения об уязвимостях, а не
все риски цепочки поставки. Тесты используют фиктивные данные и не входят в Telegram.
Проверки не заменяют независимый аудит. Отчёты могут содержать предупреждения
даже при успешном workflow; политика порога описана в самом workflow.
