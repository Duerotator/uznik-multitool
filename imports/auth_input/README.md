# Очередь создания собственных сессий

Поместите сюда свои файлы `.session`. Приложение открывает временную копию,
определяет номер, запрашивает новый код Telegram и ждёт свежее сообщение
от 777000. Если прочитать код нельзя, появится запрос ручного ввода.
2FA — ваш пароль; встроенного общего пароля нет.

Настройте собственные Telegram API-ключи. Прокси необязателен: без него и без
доступного прокси в пуле используется прямое подключение с вашего IP-адреса.
Явно заданный неисправный прокси не обходится прямым подключением.
Сессии разных библиотек определяются по структуре SQLite.

Обработка по кнопке **Process dropped sessions**; для автоматической обработки
новых файлов включите **Auto-process new auth_input files**. По умолчанию она
выключена. Папка проверяется периодически, незаконченные копирования пропускаются.

После успеха входной файл перемещается в `processed/` и не обрабатывается снова.
При ошибке остаётся в очереди. Исходный файл вне этой папки при перетаскивании
сохраняется: в очередь кладётся его копия. Собственная сессия и запись аккаунта
создаются в `data/`. Перенос в processed не завершает исходную авторизацию
в Telegram. Никакие session strings или коды не выводятся в лог.

JSON сюда не кладите: это обычный импорт через родительскую папку `imports/`.
