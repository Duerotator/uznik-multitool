# Два способа добавления аккаунтов

1. `auth_input/*.session` — создание **новой** рабочей авторизации из своей
   существующей Pyrogram/Kurigram или Telethon сессии. В GUI:
   Actions → External sessions → Open auth_input / Process dropped sessions.
2. `imports/*.session` или JSON с `backend` и `session_string` — обычный
   импорт существующей авторизации; новая авторизация не создаётся.

Ничего не положено заранее. Добавляйте только свои файлы.
Обычный импорт не затрагивает `auth_input` и её подпапки.
При первом запуске появится пустой `batch_phones.txt` для ручного пакетного
создания сессий: один свой номер в международном формате на строку.
