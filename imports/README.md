# Папка входящих файлов

Входные файлы сгруппированы по назначению:

- `*.session` и JSON для **обычного импорта** — прямо сюда. JSON содержит
  существующую авторизацию (`backend` и `session_string`).
- `auth_input/` — свои `.session`, из которых приложение создаст новую
  авторизацию. В GUI: Actions → External sessions → Open auth_input /
  Process dropped sessions. Очередь не участвует в обычном импорте.
- `emails/` — список почтовых ящиков для IMAP/POP3.

Номера для создания сессий и запускатели находятся в отдельной папке
`sessions/` в корне проекта, а не среди файлов обычного импорта.

Подробные инструкции есть в README соответствующей подпапки. Добавляйте только
свои файлы: импортируемые сессии и номера дают доступ к аккаунтам.
