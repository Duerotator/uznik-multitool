# Иконка Uznik MultiTool

`uznik-multitool.png` — оригинальный значок U с голубым угловым элементом.
Сгенерирован встроенным imagegen в режиме generate, transparent background.
`uznik-multitool.ico` — Windows-версия (16, 24, 32, 48, 64, 128, 256 px);
используется в окне приложения и ярлыке. Конвертация:
`python scripts/build_icon.py` (Pillow, инструмент разработки).
