# Собственные аватары

Добавьте свои фотографии в `male/`, `female/` или `unknown/`.
Каталог `assets/avatar_packs_raw/` — исходники перед сортировкой.
В поставке фотографий нет. Генератор профилей использует эти папки;
скачивание по вашему URL и сортировка доступны через
`scripts/profiles/download_avatar_pack.py`.
