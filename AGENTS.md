# Работа с Uznik MultiTool

Сначала прочитайте `docs/PROJECT_MAP.md` и `tests/TEST_MAP.md`, затем открывайте
только нужный код. Это desktop-only репозиторий: не добавляйте web, Bot API
сервисы, deploy или серверную синхронизацию без запроса владельца.

Сохраняйте фиксированный Comfortable и отдельные QSettings `UznikMultiTool`.
Перед коммитом выполните `tests/run_checks.py fast`. Проверки не должны
подключать реальные аккаунты или обращаться к личным сервисам.

Никогда не коммитьте `.env`, сессии, браузерные профили, базу, фильтры,
пользовательские шаблоны, логи, VPN-подписки, пароли и токены. Обновляйте карту
только при изменении точек входа / навигации. Проверяйте git diff и сохраняйте
пользовательские изменения.
