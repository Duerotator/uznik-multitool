# Сессии Telegram

Здесь собраны пользовательские входы для работы с сессиями:

- `batch_phones.txt` — свои номера, по одному на строку в международном формате.
- `create_session.bat` — создать одну сессию, введя номер по запросу.
- `batch_create_sessions.bat` — пройти номера из списка по очереди.
- `create_sessions.bat` — открыть меню входа и обработки `auth_input`.

Код инструментов находится в `scripts/sessions/`. Готовые рабочие сессии и
записи аккаунтов сохраняются отдельно в `data/sessions/` и `data/accounts.json`.
Коды Telegram и пароли 2FA вводятся в открытой консоли и не записываются в список.
Перед авторизацией заполните API ID и API Hash в корневом `.env`.
При создании автоматически выбираются модель устройства и совместимая ОС:
телефоны Android/iPhone, планшеты Android/iPad/Surface, MacBook и компьютеры
на macOS, Windows или Linux. Выбор сохраняется в `data/fingerprints.json`
и используется при последующих подключениях этой сессии. Параметры ранее
добавленных аккаунтов автоматически не меняются. Это описание MTProto-клиента,
а не эмуляция оборудования; оно не отменяет ограничения Telegram.
Без явно заданного прокси и доступного прокси в пуле используется ваш IP-адрес;
при необходимости задайте
`TELEGRAM_GLOBAL_PROXY` или добавьте и проверьте прокси в приложении.
Ожидание подключения ограничено 30 секундами, запроса кода — 45 секундами.
Если выбранное соединение недоступно, инструмент сообщит об ошибке сети.
Явно заданный неисправный прокси не обходится прямым подключением.
Ошибки меню, одиночного и пакетного входа, а также обработки `auth_input`
дописываются в `data/logs/session_creation.log`;
при аварии путь к этому файлу выводится в консоль.

Папка и список номеров создаются при запуске приложения. Файл с номерами
исключён из Git.
