# Пользовательские шаблоны

Папка поставляется без профилей и персональных значений. Добавьте свои файлы,
если используете ручное применение шаблонов:

- `first_names.txt`, `last_names.txt`, `usernames.txt`, `bios.txt` — по одному
  значению на строку;
- `profile_plan.json` — создаётся генератором профилей в интерфейсе;
- фотографии положите в `assets/avatar_packs/`.

Содержимое этих файлов игнорируется Git. Архив скачанных профилей, истории и
привязки сохраняются в `data/`, также вне репозитория.
