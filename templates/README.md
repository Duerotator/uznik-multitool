# Пользовательские шаблоны

Папка поставляется без профилей и персональных значений. Добавьте свои файлы,
если используете ручное применение шаблонов:

- `first_names.txt`, `last_names.txt`, `usernames.txt`, `bios.txt` — по одному
  значению на строку;
- `profile_plan.json` — зашифрованный план, создаётся генератором профилей;
  `profile_plan.json.key` нужен для чтения. На Windows ключ защищён DPAPI
  текущего пользователя; сохраняйте оба файла для резервной копии.
- фотографии положите в `assets/avatar_packs/`.

Содержимое этих файлов игнорируется Git. Архив скачанных профилей, истории и
привязки сохраняются в `data/`, также вне репозитория.

Старый обычный JSON-план будет зашифрован при загрузке. Защищённый план нельзя
редактировать как обычный JSON. Текстовые списки остаются открытыми.
Подробнее о переносе и защите: [данные и безопасность](../docs/SECURITY_AND_DATA.md).
